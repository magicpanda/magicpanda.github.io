# 8BitsLife

把大目标拆成每月几件小事，日积月累成就改变。

## 功能

- 📅 **未来12个月规划** — 基于成员出生年月生成专属月度计划
- ✅ **每日打卡** — 把习惯拆成可执行的小任务
- 🎯 **目标管理** — 跟踪进度，记录日志
- 👨‍👩‍👧‍👦 **家庭多成员** — 全家人共享同一应用
- ☁️ **云同步** — Firebase 实时同步多设备数据
- 🏆 **成就系统** — 解锁徽章，激励坚持
- 🎮 **人生模拟** — 虚拟角色体验人生
- 📊 **数据可视化** — 热力图、成长曲线、AI 建议

## 部署

纯前端项目，托管于 GitHub Pages。
